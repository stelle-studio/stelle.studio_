霧眉・舊眉・淡色

Brow FAQ
Q 霧眉、飄眉、飄霧眉到底差在哪？

簡單說，霧眉比較像淡淡的眉粉妝感；飄眉是做出一根一根的毛流線條；飄霧眉則是把兩種效果搭在一起。不是哪一種一定最好，我會看你的原生眉量、毛流、膚質、骨相和你平常喜歡的妝感，再決定哪一種放在你臉上會比較自然。

Q 我是油性肌，也適合做霧眉嗎？

可以，但我會先看你實際的出油狀況。油性肌通常比較容易影響留色和線條的穩定度，所以我會連毛孔、原生眉量、舊色和保養習慣一起評估；有些人反而會比較適合霧感比例高一點的做法。不是只要看到『油性肌』就直接判定不能做。

Q 眉毛很稀疏，可以做飄眉嗎？

不一定。如果原生眉毛真的很少，單做一根一根的線條反而可能會看起來比較孤零零，沒有東西可以融合。這種眉況我通常會先看缺口在哪裡、眉尾剩多少，再判斷要做霧眉、飄霧眉，還是保留一部分毛流感會比較自然。

Q 以前做過霧眉，還可以直接重做嗎？一定要先淡色嗎？

不一定要先淡色。我會先看舊色還剩多深、有沒有偏紅偏灰、範圍有沒有超出現在想做的新眉型。如果舊色已經很淡、位置也沒有干擾，可能可以直接重新設計；但如果顏色很深或舊眉範圍卡住新眉型，我就會比較建議先淡色，不會硬蓋。

Q 舊眉很紅、很灰、偏藍，要怎麼處理？

這種我不會直接拿更深的顏色硬蓋。要先看殘色有多深、範圍多大、位置有沒有跑掉；偏色比較淡時，有機會透過重新配色調整，但如果顏色很深或已經明顯影響新眉型，我會先建議淡色，再做下一步。

Q 霧眉會不會做完很濃、很像貼上去？

剛做完一定會比後面穩定後的顏色明顯一點，這是正常的。不過我的設計方向不是把每個人都做成很有妝感的眉毛，而是看你的五官、原生眉和日常習慣去抓濃淡。眉峰、眉尾、粗細也都會先畫給你確認，不是畫完就直接做。

Q 我可以拿喜歡的眉型照片給妳參考嗎？

可以，而且很歡迎你帶參考圖來，這會讓我更快知道你喜歡的是哪種感覺。不過我不會直接照著照片複製，因為每個人的眉骨、眉眼距離、臉型和原生毛流都不一樣。我會把你喜歡的元素抓出來，再重新調成適合你臉的版本。

Q 為什麼霧眉剛做完顏色很深？多久會比較自然？

這是最常讓人緊張的地方之一。剛做完顏色本來就會比較明顯，接下來還可能經過乾燥、薄痂、脫屑，甚至脫完之後一度覺得『怎麼突然變很淡』。先不要急著判斷成果，等表皮代謝、顏色慢慢穩定後再看會比較準；每個人的膚質和代謝速度也不一樣。

Q 霧眉大概可以維持多久？為什麼還要補色？

每個人差很多，沒有一個固定年限可以套在所有人身上。一般會隨時間慢慢變淡，常見大約 1～2 年可以看到不同程度的淡化，但出油、代謝、日曬、保養習慣都會影響。第一次操作後如果有些地方吃色比較好、有些比較淡，補色主要是把完整度和細節再調整一次，不代表第一次做失敗。

Q 結痂、脫屑、顏色突然變淡，是不是失敗了？

不一定，這些都可能出現在正常恢復期。尤其剛脫屑時，有些人會覺得顏色突然變得很淡，這時候先不要摳、不要補畫得太用力，也不要急著認定沒留色，照術後方式照顧、再觀察一段時間會比較準。如果是持續加劇的紅腫、疼痛或其他明顯不舒服，就不是單純看 FAQ 能判斷的，建議直接找醫療專業人員評估。

Q 修眉毛也可以預約嗎？

可以喔。如果你只是想把眉型整理乾淨，或還不確定自己要不要做霧眉，也可以先來修眉。男性、學生，或平常幾乎不化妝的人也都可以單純預約修眉，不一定要做紋繡。

美睫・睫毛管理

Lash FAQ
Q 新中式美睫跟一般接睫毛差在哪？

新中式比較重視『眼型怎麼被修飾』，不只是把睫毛接多、接長而已。我會看眼長、眼尾方向、原生睫毛能承受的重量，再去安排長短、層次和濃淡。所以同樣叫新中式，每個人最後做出來也不會完全一樣。

Q 韓式睫毛管理跟接睫毛，我該選哪一種？

如果你本身睫毛量和長度都還不錯，只是比較下垂、想讓原生睫毛翹起來，韓式睫毛管理就很適合；如果你想增加長度、濃度，或希望眼型看起來有更明顯的變化，就比較適合接睫毛。真的選不出來也沒關係，我可以直接看你的原生睫毛幫你判斷。

Q 原生睫毛短或下垂，也可以做睫毛管理嗎？

可以先評估。睫毛管理是把你原本的睫毛整理成比較捲翹、整齊的狀態，所以原生睫毛有多長、多粗，會直接影響最後效果。如果睫毛很短，但你期待的是明顯變長或變濃，我就會比較建議接睫毛。

Q 接睫毛會不會傷害原生睫毛？

不是『接了就一定會傷』，真正要看的是假睫毛有沒有超過原生睫毛能負擔的重量、分離有沒有做好，以及回家後有沒有一直拉扯或摳睫毛。我在設計時會先看原生睫毛的粗細和健康狀況，不會為了做得很濃就什麼長度都往上接。

Q 美睫會不會讓眼睛看起來太濃或太成熟？

不一定，濃不濃其實跟根數、長度、捲度、排列方式都有關。我不會預設每個人都要做很濃，反而會先問你平常有沒有化妝、喜歡多有存在感，再依眼型去調整。想做很自然也完全可以。

Q 嫁接美睫大概可以維持多久？

一般常見大約 3～5 週，但每個人的掉落速度真的差很多。原生睫毛本來就會代謝，加上睡姿、清潔方式、眼周保養品和生活習慣，都會影響留存。不是到了第幾週就突然全部掉光，而是會慢慢變少，再看狀況決定要補睫還是重新接。

Q 做完美睫或睫毛管理後可以正常洗臉嗎？

可以，眼周還是要正常清潔，只是不要大力搓揉或拉扯睫毛。接睫毛的話，也盡量不要讓很油的保養品一直堆在睫毛根部。完成後我會再跟你說日常怎麼洗、怎麼照顧，不需要因為接睫毛就不敢碰水。

Q 敏感眼或容易流淚，可以做美睫嗎？

可以先跟我說你的狀況，我會再評估。容易流淚本身不代表一定不能接，但如果最近眼睛有紅腫、發炎、明顯不舒服，或剛做完眼部相關處理，我就會建議先不要勉強操作。需要醫療判斷的狀況，還是先給醫師看會比較安全。

Q 美睫預約前，需要先卸眼妝嗎？

建議當天不要擦睫毛膏、眼線膠或很濃的眼妝，這樣我比較好看清楚你的原生睫毛，也不需要花太多時間處理殘妝和油脂。如果你有戴隱形眼鏡、眼睛本身又比較敏感，也可以自己帶眼鏡來備用。

霧唇・深唇・舊色

Lip FAQ
Q 什麼樣的人適合做霧唇？

如果你覺得自己素顏時唇色比較沒精神、顏色不均，或平常很依賴口紅，就可以來評估霧唇。不過我不會把每個人都做成同一個粉色或高飽和唇色，會先看你的原生唇色、膚色和你平常喜歡的妝感，再決定適合的方向。

Q 深唇可以直接做粉色或明亮色嗎？

不一定。原生唇色越深，底色對最後呈色的影響就越大，所以看到別人的粉嫩色，不代表做在自己嘴唇上也會完全一樣。我會先看你的底色和唇周色差，再判斷適不適合直接做，還是要分階段調整。

Q 唇色暗沉一定要先做淡色嗎？

不一定。我會先看你是天生唇色比較深、局部色差明顯，還是以前做過霧唇留下舊色。程度比較輕時，不一定需要先淡色；如果底色很深、顏色很不均，或舊色會干擾新的色系，才會再討論要不要分階段處理。

Q 霧唇和唇淡色還原有什麼差異？

霧唇比較像是在你原本的唇色上，重新規劃整體色感和氣色；唇淡色還原則比較偏向先處理原本很深、很不均，或有舊色干擾的狀況。實際要做哪一種，我還是會先看你的原生唇色，不會只看你想要的參考照就直接決定。

Q 以前做過霧唇、有舊色，還可以直接重做嗎？

要先看舊色剩多少、顏色有沒有偏掉，以及範圍有沒有超出現在的唇形。舊色已經很淡、位置也沒問題，可能可以直接重新規劃；但如果顏色還很深或會干擾新的色系，我就不會建議直接硬蓋，會先跟你說比較適合怎麼處理。

Q 霧唇可以規劃成自然的日常氣色感嗎？

可以，我自己也比較喜歡自然、平常素顏就能看的色感。不過最後會呈現到什麼程度，還是會受原生唇色、膚色和唇況影響。參考照可以給我看，但我會把它當作你喜歡的方向，不會跟你保證能做成一模一樣的顏色。

Q 霧唇多久恢復？為什麼剛做完顏色很深？

剛做完顏色比最後穩定後深很多，其實很正常。前幾天也可能覺得乾、緊、開始脫屑，脫完之後甚至一度覺得顏色變很淡。這些都要再給它一點時間慢慢穩定，所以不要用操作當天就判斷最後顏色；每個人的恢復速度也會不一樣。

Q 唇部很乾、容易脫皮，可以預約霧唇嗎？

可以先傳照片給我看。如果只是平常偏乾，可以先把保濕做好；但如果已經乾裂、破皮或唇況很不穩定，我會比較建議先養好再約。操作前也不要突然很用力去角質、撕唇皮，反而容易把嘴唇弄得更敏感。

Q 霧唇顏色可以指定跟照片一樣嗎？

照片可以拿來當參考，但真的沒辦法保證一模一樣。每個人的原生底色、膚色和留色反應都不同，同一個色系做在不同人身上也會有差。我比較會先抓你喜歡的『色感方向』，再依你的底色去調整。

Q 有唇疱疹病史，可以做霧唇嗎？

有唇疱疹病史一定要在預約前先跟我說。如果當下正在發作、有水泡或破皮，我不會操作。至於你的狀況是否適合做、需不需要任何預防性用藥，這部分要由醫師判斷，我不會在美容諮詢裡直接叫你吃什麼藥。

Q 霧唇預約前需要注意什麼？

最基本的就是先把唇況養穩、做好保濕，不要讓預約當天嘴唇還在嚴重乾裂或破皮。如果你有唇疱疹病史、最近正在就醫、使用特殊產品，或有其他身體狀況，也請先跟我說，這樣我才能判斷要不要先暫緩。

材料・操作・衛生

Material & Process FAQ
Q 霧眉使用的是什麼品牌的色乳？

我目前霧眉使用的是 Hanafy 專業紋繡色乳。Hanafy 本身有不同系列和色號，我會依你的原生膚色、舊色和想要的眉色去搭配，不是所有人都用同一個顏色。如果你本身很在意品牌、色號或成分，也可以在預約前直接問我。

Q Hanafy 色乳有 SGS／REACH 之類的檢測嗎？

這題我不會直接用一句『有認證、很安全』帶過，因為不同系列、不同色號能提供的文件不一定完全相同。Hanafy 官方有公開產品製造、成分與 MSDS 等相關資訊；如果你特別在意某一個檢測或某個色號，預約前可以直接問我，我會以實際使用的產品資料為準，不把 SGS／REACH 當成整個品牌通用的保證。

Q 霧眉之後會不會變紅、變藍？

沒有任何色乳可以只靠品牌就保證永遠不變色。後續顏色會受到原生膚色、配色、操作深度、個人代謝、日曬和照護等很多因素影響。我能做的是一開始就依你的條件去選色、控制濃度，讓之後退色比較自然，也保留未來好調整的空間。

Q 霧眉、霧唇會很痛嗎？

每個人的痛感差很多，所以我不會跟你說『完全無痛』。有人覺得只是微微刺、有些人本身就比較敏感；如果你很怕痛，可以預約前先跟我說。操作過程中如果真的不舒服，也可以隨時告訴我，不需要硬撐。

Q 敏感肌也可以做霧眉或霧唇嗎？

可以先評估，但我不會只看到『敏感肌』三個字就直接回答可以或不可以。如果你最近有明顯紅腫、皮膚炎、破皮、過敏反應，或正在接受相關治療，我會建議先把狀況穩定下來。牽涉到疾病、藥物或醫療判斷的部分，還是要先問醫師。

Q 懷孕或哺乳期間可以做霧眉、霧唇嗎？

懷孕或哺乳期間請先跟我說。我不會只靠網路資訊直接替你判定『一定可以』，因為每個人的身體狀況不同，也會牽涉到操作產品與個人評估。如果你真的很想做，會比較建議先問自己的產科醫師，再決定要不要把操作延後。

Q 操作用的針具和耗材是怎麼處理的？

該拋棄的針具和直接接觸耗材，我都以單次使用為原則，不會拿同一份再給下一位客人使用。如果你很在意現場的針具、耗材或衛生流程，也可以操作前直接問我、現場確認，我不會介意。
